# AppFX Sampler
Sample application for [AppFX](https://github.com/MaximKnaub/app-fx), a small DI Framework for JavaFX

## Requirements
- Java 27 or newer
- AppFX 0.3 in the local Maven repository, as it is not available on Maven Central: clone [AppFX](https://github.com/MaximKnaub/app-fx) and run `mvn install`

## Run
```
mvn javafx:run
```
